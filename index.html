Count the records.

Compare two CRM snapshots by their stable source IDs. Find missing records, duplicated identities, broken company associations and changed subscription choices before transferring send authority.

Runs in your browser. Snapshot content is never uploaded by this tool. No account, external libraries, analytics or storage. Keep exports minimal and close the tab when finished.

Reconcile a snapshot

The preloaded example is synthetic. It produces four exceptions: an email opt-in mismatch, a changed company association, one missing record and one unexpected target record. Record D is deliberately excluded.

Input format and comparison rules

Paste JSON arrays. Every record needs source_id (nonempty string), company_id (nonempty string or null), email_opt_in and sms_opt_in (booleans). Target exports must retain the original source ID. Compare translated company IDs in the same namespace.

The tool uses exact, case-sensitive ID equality. It never merges identities by email or chooses one record from duplicate IDs. Exclusions are an explicit list of source IDs that should be absent from the target. Unknown exclusions and excluded records still present in the target are reported.

Limit: 25,000 records and 12 MB of JSON text per side. A JSON report includes the compared IDs and values, so handle that download as migration data. Invalid input stops comparison rather than producing a partial pass.

A clean comparison is one gate, not a cutover decision.

This checker compares only the supplied snapshots and four required fields. It does not prove export completeness, timing consistency, association ownership, event replay, consent provenance, delivery eligibility or restoration readiness. A later legitimate preference change can produce a difference: investigate it instead of overwriting it.
